## 复现与检查

在项目根目录执行：

```sh
.venv_inference/bin/python demo_video/2026-09-25/edit/render_clips.py
.venv_inference/bin/python demo_video/2026-09-25/edit/render_pages.py
.venv_inference/bin/python demo_video/2026-09-25/edit/verify_v2.py
```

`edit/edit_decisions.json` 为当前完整保留规则。`edit/verification.json` 记录实际解码帧数、首尾帧视觉比对、完整片段拼接帧数、导出完整解码与原始素材哈希检查结果。首尾帧比对允许重新编码导致的像素误差，不代表文件字节相同。
